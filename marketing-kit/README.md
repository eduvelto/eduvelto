## Honesty rules (binding — every file follows them)

- Only true numbers: 609 books, 2,307 chapters, 23,259 questions,
  1,014 exams, bilingual Bangla + English. Library covers
  Class 9–Honours only — never claim any other class range.
- No admission/circular status claims, no outcome guarantees, no
  "common" promises of any kind, no mock-test claims (mocks are
  not live), no live-AI-teacher claims (AI Teacher is a scripted
  demo; the working AI tools are calculators, letters, CV, budget).
- No invented clients, revenue, followers or testimonials.
- Eduvelto is the owner's own platform (eduvelto.com) — described
  as such, never as client work.
- The website gig is marked DRAFT: it is approved but not yet live
  (4-gig limit — which live gig to pause is the owner's decision).
  Never present it as live.

## How to use

1. Copy one post or script at a time — do not bulk-post all 30
   in one day.
2. Replace `[ ]` placeholders (buyer name, business name, link)
   before sending any outreach or proposal.
3. Post link in the first comment where the group allows it;
   otherwise put eduvelto.com at the end of the post.
4. If any number here changes (new books, new verified questions),
   update this kit and the site copy together — never edit a
   number in one place only.
